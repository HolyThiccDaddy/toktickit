Answer Part 8: Owned Ticket Screen - View Mode and Attachments (5 Points)

Ticket Detail is read-only for owned tickets. Requesters can add a permitted attachment, download an active attachment, and soft-remove an attachment with a non-empty reason. Removed metadata remains visible while download is blocked. Cross-requester detail and attachment access is rejected by the API.
